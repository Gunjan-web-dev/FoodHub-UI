# FoodHub-UI
A modern food cards UI built using React and CSS Grid.
## 🚀 Features

- Responsive card layout
- CSS Grid system
- Hover animations
- Box shadow effects
- Modern clean UI
- Reusable React components

## 🛠️ Technologies Used

- React
- JavaScript
- CSS3
- HTML5

## 📂 Project Structure

```bash
src/
│
├── components/
│   ├── App.jsx
│   └── Card.jsx
│
├── dishes.js
├── index.js
└── styles.css
```

## 🎨 UI Features

- 3 cards per row layout
- Smooth hover scale animation
- Soft modern shadows
- Rounded corners
- Food image cards

## 📸 Preview

This project displays food dishes with:
- Dish name
- Ingredients
- Price
- Food image

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/flavorgrid.git
```

Go to project folder:

```bash
cd flavorgrid
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```
